# الخطة الدراسية لبرنامج بكالوريوس علوم الحاسب (نظام الفصلين) — نموذج (2-6)

- القسم: علوم الحاسب (Computer Science)

صيغة كل سطر: رمز ورقم المقرر — اسم المقرر بالعربي (الاسم بالإنجليزي) — إجباري أو اختياري — الساعات (نظري/عملي/المجموع) — المتطلب السابق.
